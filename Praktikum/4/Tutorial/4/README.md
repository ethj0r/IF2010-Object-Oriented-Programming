Deskripsi

Diberikan dua buah file interface:

CanRun.java

CanSwim.java



Tugas Anda

Dengan memanfaatkan interface diatas, implementasikan tiga buah class berikut:

Human.java : Manusia bisa berlari dan berenang

Fish.java : Ikan bisa berenang

Dog.java : Anjing bisa berlari



Pengujian

Gunakan file Main.java untuk menguji implementasi Anda.

Contoh output untuk test case 4:

Ikan berenang.
Anjing berlari.
Manusia berlari.
Manusia berenang.

Deliverables
